💤 Member AFK & Ping Tracker

Open AFK protocol for all server members. Automatically prefixes nicknames to [AFK], tracks mentions with Discord jump links, suppresses autoresponders during AFK, and welcomes members back upon their next message.

1. Nickname Prefix
Running /afk [reason] automatically changes the member's server nickname to [AFK] <name>.
2. Mention Alerts
When someone pings an AFK user, Friday informs them of the reason and duration away, and saves the message jump link.
3. Autoresponder Mute
If an admin or user with an active autoresponder goes AFK, Friday mutes it while AFK so no double-replies occur.
4. Auto Return
Sending any message automatically removes AFK, restores original nickname, and compiles all missed pings with jump links.
