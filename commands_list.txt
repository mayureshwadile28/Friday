Friday Bot - Complete Command List
==================================

🛡️ Moderation
/ban @member [reason] - Bans a member from the server
/unban <user> [reason] - Unbans a user by username, tag, or numeric ID (with live autocomplete dropdown)
/warn @member [reason] [delivery] - Issues formal warning with flexible delivery (Both, DM Only, or Channel Chat)
/warnings @member - Review active warning history for a member
/clearwarns @member [warn_id] - Clear all warnings or a specific warning ID for a member
/timeout @member <minutes> [reason] - Mutes a member for a duration
/untimeout @member [reason] - Removes an active timeout early
/purge <amount> - Bulk-deletes messages in the current channel
@Friday @member <new nickname> - Changes a user's nickname (requires Manage Nicknames perm)

⚙️ Security (Anti-Nuke, Anti-Raid & Command Center)
/antinuke_toggle <ON/OFF> - Enables or disables the entire master anti-nuke engine
/antiraid <enable/disable> - Toggle high-speed mass join velocity tracking & auto-quarantine
/antispam <enable/disable> - Toggle rapid message burst, duplicate flood filter & auto-mute
/security_status - Comprehensive status overview of all 10 security audit channels & matrices
/antinuke_limit <action> <limit> - Sets rate-limit thresholds (Bans, Kicks, Channels, Roles)
/antinuke_refresh - Auto-creates the "Friday Security Logs" category and all 10 audit channels:
  #audit-antiraid, #audit-antispam, #audit-roles, #audit-channels, #audit-antinuke,
  #audit-banned, #audit-deleted, #audit-timeouts, #audit-whitelisted, #audit-abuse
/antinuke_sync - Auto-scans and re-links existing security audit channels across the server
/whitelist_add @user - Makes a user immune to anti-nuke, anti-raid, and anti-spam detection
/whitelist_remove @user - Removes a user's security immunity

🤖 AI Assistant & Conversations (Groq / OpenRouter / Gemini Pipeline)
/ask <question> - Ask Friday anything directly with her charming lady personality and real-time knowledge
/clearchat - Reset your recent multi-turn conversation memory with Friday in the current channel
/mymemory <view/clear> - Inspect what friendly personal memories Friday remembers about you, or clear them
/server_instruction <add/view/clear> [instruction] - Configure server-wide behavioral instructions for Friday (Admin & Owner only)
Chat Trigger: Tagging @Friday or replying to her messages initiates a smart conversation with contextual memory, live Google news search, live date/time handling, and safe mention sanitization

💤 Member AFK System
/afk [reason] - Sets your status to AFK with an optional reason (e.g. Studying, Lunch, Sleeping)
  • Automatically prefixes your server nickname with [AFK] and reverts it upon return
  • Notifies members who tag or reply to you with your away reason and duration
  • Records all missed pings with channel tags and [Jump to Message] links
  • Automatically welcomes you back and displays your missed pings summary on your next message
  • Automatically suppresses conflicting mention auto-responses while you are AFK

👋 First Message Welcome Engine
/first_welcome set [channel] - Set the destination channel for first-chat greetings (leave empty for current channel)
/first_welcome disable - Disables first-message welcome greetings for this server
/first_welcome status - Views current first-welcome configuration, target channel, and theme
/first_welcome test - Sends an authentic test welcome card to preview the layout and styling
/first_welcome message <template> - Updates the welcome message format with live variables
/first_welcome reset [member] - Resets first-welcome status for a specific member or all members to re-trigger greetings
/set_welcomer [mode] [channel] - Quick shortcut command to set the welcome channel
/set_first_welcome [channel] - Standalone shortcut to set the first-welcome channel to current channel

🔒 Channel Privacy & Lockdown
/private [channel] - Makes a specific channel private
/unprivate [channel] [all_channels] - Unprivates a specific channel or ALL channels (Protects Security Logs)
/private_category <category> - Makes an entire category and all its channels private
/unprivate_category <category> - Unprivates a category and all its channels (Blocks Security Logs)
/ignore_private_add <channel> - Adds a channel to the ignore list (won't be fully hidden by lockdown)
/ignore_private_remove <channel> - Removes a channel from the ignore list
/force_private - Initiates Lockdown: Makes all channels private EXCEPT ignored channels, which become Read-Only.

🤬 Anti-Abuse Chat Filter
/anti_abuse <words> - Add words to the filter (comma-separated)
/anti_abuse_remove <word> - Remove a specific word from the filter
/anti_abuse_list - View all currently banned words
/anti_abuse_whitelist_add @user - Make a user immune to the word filter
/anti_abuse_whitelist_remove @user - Remove a user's immunity

🎉 Community & Leveling
/level_setup #channel - Activates leveling and sets the notification channel
/level_mode <text/image/both> - Choose level-up notification dispatch: Text Only, Graphical Image Card, or Both
/rank [@user] - Shows a visual rank card (custom generated image)
/leaderboard - Displays the top 10 most active members
/joke [category] - Returns a hilarious Hinglish, Desi, or tech joke from a library of 420 jokes with an interactive 'Next Joke 🔄' button

🎨 Expressions, Reactions & Keyword Auto-Responder
/emoji_steal <emojis> - Paste one or more custom emojis to bulk-steal them
Right-Click -> Apps -> Steal Sticker - Steal a sticker from a message
/autoreact add @member <emoji> - Automatically reacts with an emoji when @member is mentioned
/autoreact remove @member - Removes the auto-reaction rule for @member
/autoreact list - Lists all active auto-reaction mention rules
/autoresponder add <response> [member] [keyword] [emoji] - Auto-replies and/or reacts when @member is mentioned OR when a standalone keyword/word is typed ({author} and {user} supported). Uses strict word boundaries so words like 'ip' trigger on 'what is the ip?' but strictly NOT on 'IPL' or 'equipment'.
/autoresponder remove [member] [keyword] - Removes the auto-responder rule for @member or keyword
/autoresponder list - Lists all active auto-responder rules (mentions and keywords) and ignored channels
/autoresponder ignore_channel #channel - Disables auto-responses in the specified channel
/autoresponder unignore_channel #channel - Re-enables auto-responses in an ignored channel

🎭 Reaction Roles
/reaction_panel - Creates an embed panel with up to 3 emoji-role pairs

📢 Self Announcements Dispatcher
/announcement <channel> - Configures or overwrites the official announcement destination channel
Reply shortcut: In any staff/chat channel, reply to your draft announcement and tag "@Friday announcement kardo" / "@Friday announcement do it" - Friday retrieves the draft message, embeds, and attachments, and immediately broadcasts them to the destination channel. (If not configured yet, Friday prompts to set up with /announcement first).

/ping - Shows bot latency confirmation

🎫 Ticket System
/ticket create_ticket_panel <channel> <title> <desc> <btn1> <cat> ... - Deploys an interactive support panel
/ticket handle_role <role> - Designates a staff role to be pinged and given access when a ticket opens

🎵 Music & High-Fidelity Audio (Pure YouTube Engine)
/join - Connect Friday to your current voice channel
/leave - Stop playback, clear queue, and disconnect Friday from voice channel
/play <music> - Search & stream official tracks strictly from YouTube with live autocomplete, high-fidelity 48kHz audio, balanced grid controls (Row 0: Pause, Skip, Shuffle, Loop, Stop [Danger]; Row 1: Queue, Like [Success], Vol -, Vol +), and an interactive DSP Equalizer dropdown
/soundtest - Play a 2-second studio test chime to verify voice channel audio output
/pause - Pause currently active music playback
/resume - Resume paused music playback
/skip - Skip current track to the next song in the queue
/shuffle - Randomly shuffle upcoming songs in the queue
/volume <1-200> - Adjust master playback volume percentage
/queue - View active playlist and upcoming queued tracks in clean box embed format
/likes - View your personal saved favorite tracks
/filter <preset> - Set audio mastering & EQ profiles in real time without restarting the track (🎧 Studio Master, 🔊 Bass Boost, 🎙️ Vocal Boost, 🌙 Nightcore, ☕ Lo-Fi, 🎼 Treble Boost, 🌀 8D Spatial Audio, ⚡ Flat)
/stop - Stop playback immediately and clear the entire music queue

🖼️ Media Only Channels

/media_whitelist_add [user] [role] - Exempt a member or role from media-only channel chat deletion

/media_whitelist_list - View all members and roles exempt from media-only channel deletion
